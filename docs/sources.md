## 术语考证
- `§〇`：原仓库 README 术语表说明「`§〇` · `§一` · `§6.4` —— 文档内部节号」。`§〇 当前交接` 是场景记忆文件的第 0 节，AI 开场「读场景记忆」读的就是它（`00-核心机制/三-场景体系.md`「④ 读场景记忆的 §〇」）；视频 02:11 画面写作「§0 当前交接」。本站正文统一写「场景记忆 · 开头交接」。
- `场景画像.md`：工具生成的布局 / 面板 / 渲染器说明（`05-协作与规矩/一-全局铁律.md`），不是「相处方式」；相处方式是 `00-核心机制/六-场景即人的一面.md` 的场景人格，在共享层。
