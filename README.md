# DSH 神经终端 · DeepSeek Harness 学习站

把博主「淋雨家 / 马上淋雨」的 DSH（DeepSeek Harness）AI 工作台设计理念，整理成一个**从理念到实战**的赛博风学习网站。

- 前端：原生 ES Module + three.js（CDN importmap），零构建、零 npm 依赖
- 内容：全景架构图（每章标出所在板块）、每章「大白话」类比 + 原作者配图、六层结构、三机制、身份认领、MCP 接免费 AI、派单、专题、把规矩变成机制、从零到能跑、踩坑、情境测验

## 本地运行

```bash
python3 -m http.server 8731
```

打开 http://localhost:8731
